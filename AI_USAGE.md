# AI Usage

I used AI tools (mainly ChatGPT and GitHub Copilot) to speed up development of this project.  
Here’s how they helped:

- **Coding:** Suggested React + TypeScript code patterns, Tailwind classes, and helped with image upload/downscale logic.  
- **Debugging:** Pointed out small mistakes (like state handling, retry logic, and accessibility issues).  
- **Testing:** Gave me starter examples for unit tests with React Testing Library and ideas for retry/backoff test cases.  
- **Docs & Cleanup:** Helped write this file, project description, and some commit messages in clearer language.  

All final code was reviewed, edited, and tested by me before adding to the project.
